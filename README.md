Unity轉盤製作流程與操作說明

一、製作流程
1. 建立遊戲畫面
先在 Unity 建立 2D 專案，並將畫面設定成適合手機使用的直式 9:16 比例。接著使用 Canvas 製作介面，主要分成兩個畫面，一個是輸入選項的畫面，另一個是轉盤畫面。使用者可以先設定選項，再進入轉盤進行抽選。
2. 製作選項輸入功能
使用 WheelManager.cs 控制選項數量及輸入欄位。使用者可以自行設定 2～12 個選項，按下建立按鈕後，程式會依照輸入的數量，自動產生對應的文字輸入框。目前選項名稱以英文輸入為主。完成輸入後，程式會讀取各個選項的名稱，並將資料傳送到轉盤。
3. 製作轉盤
使用 WheelRenderer.cs 繪製轉盤。先將圓形的 360 度除以選項數量，計算每個選項所佔的角度，再利用 VertexHelper 繪製不同顏色的扇形。例如輸入 4 個選項，每個扇形就是 90 度；輸入 6 個選項，每個扇形就是 60 度。接著使用 TextMeshPro 顯示英文選項名稱，並透過角度計算文字的位置，讓每個選項都能顯示在對應的扇形上。
4. 製作旋轉功能
使用 WheelSpinner.cs 控制轉盤旋轉。當使用者按下 SPIN 按鈕時，轉盤會開始旋轉，並搭配旋轉音效。利用 Coroutine 控制旋轉過程，讓轉盤逐漸減速，最後停在隨機的位置。指針固定不動，轉盤停止後，指針所指的選項就是抽選結果。
5. 設定畫面切換
使用 ScreenManager.cs 管理畫面切換。一開始先顯示選項設定畫面，等使用者完成選項輸入並按下開始按鈕後，再切換到轉盤畫面。
6. 測試與修改
完成基本功能後，在 Unity 中測試不同的選項數量，確認轉盤分割、文字顯示及旋轉功能是否正常。
測試時發現，輸入 2 個選項雖然可以正常產生兩個半圓，但選項名稱沒有顯示。
後來檢查 WheelRenderer.cs，發現文字框寬度的計算使用了 tan(90°)，導致數值異常。因此針對 2 個選項另外設定文字框寬度，修改後就能正常顯示。
7. 匯出成 iPhone App
完成 Unity 專案後，將 Build Profiles 切換成 iOS 平台，並透過 Unity 產生 Xcode 專案。接著在 Xcode 設定開發者帳號、簽章及連接的 iPhone，將 App 安裝到手機進行測試。
一開始安裝後，手機只顯示藍色畫面。後來檢查發現，Build Profiles 的 Scene List 放的是 SampleScene，不是實際製作轉盤的 MainScene。將啟動場景改成 MainScene，重新 Build 並安裝後，手機就能正常顯示轉盤介面。

二、操作方式
1. 開啟 App
點選手機上的 Lucky Wheel App，進入選項設定畫面。
2. 輸入選項數量
輸入想要抽選的選項數量，範圍為 2～12 個。
3. 建立選項
按下建立按鈕後，系統會依照輸入的數量，自動產生對應的文字輸入框。
4. 輸入選項內容
在每個輸入框填入英文選項名稱，例如 Apple、Banana、Orange 等。目前轉盤僅支援英文文字顯示。
5. 進入轉盤畫面
完成選項設定後，按下開始按鈕，進入轉盤畫面。轉盤會依照選項數量自動分割，並顯示剛剛輸入的英文名稱。
6. 開始旋轉
按下 SPIN 按鈕，轉盤開始旋轉，同時播放音效。
7. 查看結果
等待轉盤逐漸減速並停止，最後指針指向的選項就是抽選結果。
